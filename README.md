## About the Project

**The-Blairs-Revenge-2D** is a **2D game project** developed primarily to expand my knowledge in game development using the **Unity** engine and **C#** programming language.

This project serves as a focused learning environment where I am actively exploring and applying the various tools and concepts that Unity offers for creating engaging, interactive experiences.

### Learning Goals

With this project, I am concentrating on implementing and mastering the following concepts:

* **C# Game Scripts:** Implementing game logic, player controls, and object interactions.
* **Physics:** Utilizing **Colliders** and **Rigidbodies** for movement and collision detection.
* **Graphics & Assets:** Working with **Sprites**, **Textures**, and **Animations**.
* **Game Environment:** Setting up **Lighting**, **Camera** systems, and effects.
* **Sound Design:** Implementing **Music** and sound effects.
* **Level Design:** Creating and designing game levels and environments.

### Future Plans

My next steps are focused on:
1.  Applying the knowledge gained from this project to new game developments.
2.  Participating in a **Game Jam**.

## 🚀 Getting Started

To view and run the project on your local machine, you will need the **Unity Hub** and the corresponding **Unity Editor** version installed.

### Prerequisites

* **Unity Hub**
* **Unity Editor** (*Please specify the exact version here, e.g., Unity 2021.3 LTS*)
* **Visual Studio Code** (or Visual Studio) for C# script editing.

### Cloning the Repository

```bash
git clone [https://github.com/BrunoSchmitz4/The-Blairs-Revenge-2D.git](https://github.com/BrunoSchmitz4/The-Blairs-Revenge-2D.git)
cd The-Blairs-Revenge-2D
```

## Running the Game
1. Open Unity Hub.

2. Click on "Add" and select the root The-Blairs-Revenge-2D folder you just cloned.

3. Open the project through Unity Hub.

4. In the Unity Editor, navigate to the main Scene (usually located in Assets/Scenes/) and press the Play button to start the game.
